# Webprogramozás PHP-ben

Egyetemi jegyzet a szerveroldali webprogramozás alapjairól PHP nyelven.  
A jegyzet a Sapientia Erdélyi Magyar Tudományegyetem Csíkszeredai Karán készült.

## A jegyzet

A tíz fejezet egymásra épülve vezeti be a szerveroldali webfejlesztés főbb fogalmait:

| Fejezet | Téma |
|---------|------|
| 1 | Bevezetés: a web működése, fejlesztői környezet |
| 2 | PHP alapok: szintaxis, típusok, vezérlési szerkezetek |
| 3 | Objektumorientált programozás |
| 4 | Űrlapkezelés és fájlfeltöltés |
| 5 | Munkamenetek és sütik |
| 6 | Adatbázis-kezelés (PDO) |
| 7 | REST API-fejlesztés |
| 8 | Composer és függőségkezelés |
| 9 | MVC-architektúra |
| 10 | Automatizált tesztelés és verziókezelés |

## Kódpéldák és megoldások

A `kodpeldak/` mappában fejezetenként megtalálhatók a jegyzetben szereplő kódpéldák, a `megoldasok/` mappában pedig a gyakorló feladatok megoldásai.

### Követelmények

- PHP 8.1 vagy újabb
- Composer (a 8. fejezet megoldásaihoz)

### Futtatás

A legtöbb példa PHP beépített szerverével közvetlenül futtatható:

```bash
